# Отложенный код фронтенда

Здесь лежит то, что перестало вызываться после отказа от автовыкладки и
нейросети, но выбрасывать жалко: логика в нём рабочая и понадобится, если
эти части вернутся.

- `sanitize.ts` — санитайзер HTML под `v-html`. Писался для описаний,
  которые генерировала нейросеть. Сейчас `v-html` в приложении не
  используется ни разу, весь текст выводится через `{{ }}`.
- `discount.ts` — расчёт скидок для шаблонов автопостинга.

Файлы вне `src/shared`, поэтому в сборку не попадают. Вернуть — перенести
обратно и добавить вызовы.
